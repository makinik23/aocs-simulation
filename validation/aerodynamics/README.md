# Single-plate Sentman reference

`data/sentman_single_plate_reference.csv` contains frozen force-coefficient
cases generated with ADBSat's independent `coeff_sentman.m` implementation.

Reference source:

- Repository: <https://github.com/nhcrisp/ADBSat>
- Commit: `d213fa9b5aa1c72e128cf87a812b3b56f61d7d9e`
- File: `toolbox/fmf_eq/coeff_sentman.m`
- Model: Sentman with the Schamberg incomplete-accommodation modification and
  the Koppenwallner one-half correction used by ADBSat.

The fixture covers a single zero-thickness plate for six atmospheric species,
incidence angle, molecular speed ratio, wall temperature, energy accommodation,
and a representative multispecies mixture. The production model is not called
while generating the reference.

To regenerate the fixture, obtain the pinned ADBSat revision and run:

```matlab
addpath("validation/aerodynamics")
generateSinglePlateSentmanReference("/path/to/ADBSat")
```

The single-plate fixture includes grazing and leeward incidence through 180
degrees. These cases verify the thermal Maxwellian contribution retained by
the complete Sentman equations instead of applying a hyperthermal back-face
cutoff.

`data/sentman_3u_cuboid_reference.csv` is generated by the complete ADBSat
mesh pipeline from `geometry/cubesat_3u.obj`. The 0.1 x 0.1 x 0.3 m convex
geometry is evaluated over 324 angle-of-attack and sideslip combinations. The
fixture stores force and moment vectors transformed back into the OBJ geometric
axes used as body axes by the Simulink test.

To regenerate both fixtures from the pinned ADBSat checkout:

```matlab
addpath("validation/aerodynamics")
generateSinglePlateSentmanReference("/path/to/ADBSat")
generateThreeUCuboidSentmanReference("/path/to/ADBSat")
```
